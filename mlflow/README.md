# MLflow local store

This directory holds the local, SQLite-backed MLflow tracking store and model registry.

- `tracking.db` — committed. Run history + registry stages (small; params/metrics/tags only).
- `artifacts/` — gitignored. Heavy run artifacts; regenerated by re-running the training scripts.

Launch the UI with `pnpm mlflow:ui` (or see `docs/mlflow.md`).
